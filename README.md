## About

I'm a **Machine Learning Engineer and AI Systems Builder** focused on understanding how intelligent systems work from the inside out.

My work spans machine learning libraries, deep learning architectures, transformers, AI-powered applications, backend systems, and reproducible ML pipelines.

Rather than treating ML frameworks as black boxes, I like building the underlying components myself and understanding the mathematics, algorithms, data flow, and engineering decisions behind them.

# Featured Projects

## rslearn-ML

**Machine Learning library built from scratch**

A custom ML library inspired by the design philosophy of Scikit-learn, focused on implementing machine learning workflows while keeping the underlying algorithms understandable and accessible.

**Highlights**

* Custom ML algorithms
* Preprocessing pipeline
* Model evaluation
* Dataset handling
* Scikit-learn-inspired API design
* Python package distribution through PyPI
* Automated testing and development workflow

**Repository:** `ItzRustam/rslearn-ML`

---

## Transformer

**Decoder-style Transformer implementation**

A transformer architecture implemented from the ground up to understand the internal mechanics of modern sequence models.

**Core concepts**

* Token embeddings
* Positional representations
* Self-attention
* Multi-head attention
* Feed-forward networks
* Residual connections
* Layer normalization
* Decoder blocks
* Training pipeline

The goal is not simply to use a transformer, but to understand the architecture that makes it work.

**Repository:** `ItzRustam/transformer`

```text

Benchmark it

        ↓
Document it
        ↓
Deploy it
```

I prefer understanding systems at the implementation level rather than treating frameworks as black boxes.
